# Student Task Manager

A simple, lightweight, client-side task manager designed to help students track and organize their daily academic tasks.

## Description
This application provides a clean, self-contained dashboard where students can quickly add tasks, specify due dates, prioritize assignments, toggle completion states, and delete tasks.

## Purpose / Learning Objective
This project was created as a **practice and learning exercise** to demonstrate basic front-end development concepts:
* Structuring interactive web interfaces with semantic HTML5 and vanilla CSS3.
* Managing application state (CRUD operations) using native JavaScript arrays.
* Persisting application data on the client side using the HTML5 Web Storage API (`localStorage`).
* Modifying and manipulating the DOM dynamically in response to user actions.

## Features
* **Create**: Add tasks with customized titles, due dates, and priority levels (Low, Medium, High).
* **Read**: Dynamic list rendering displaying current tasks, colored indicators by priority level, and formatted dates.
* **Update**: Mark tasks as completed with a checkbox toggle (visual opacity and line-through styling), or edit task details (title, due date, and priority) inline via editable form fields.
* **Delete**: Delete unwanted tasks from the list with an instant confirmation prompt.
* **Local Persistence**: Save changes automatically so tasks remain intact after closing or refreshing the browser window.

## Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling & Layout)
* **Vanilla JavaScript (ES6+)** (Interactive Logic & State Management)
* **LocalStorage API** (Client-side Persistence)

## How to Run the Project Locally
No build step, servers, or dependencies are required. 
1. Clone or download this repository.
2. Navigate to the project folder.
3. Open `index.html` directly in any modern web browser (Double-click or drag-and-drop into a browser window).

## Current Project Status
This repository is a **practice/learning project** and is intentionally kept as a basic, minimalist implementation. There are no plans to introduce advanced features such as user accounts, server databases, notification systems, or multi-device syncing. It serves as a static snapshot of beginner front-end learning.
